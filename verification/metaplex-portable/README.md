# Portable Compression and Metaplex contracts

This private fixture imports the public crates' original contract bodies. The
`metaplex-contracts` generator derives the registry from their Rust functions and
literal case macros. It also includes Bubblegum's provider normalization, proof
binding and cancellation bodies. Original assertions stay with their public owners.

The native executable and both WASI previews emit the complete named case stream.
The browser calls the same registry. The interpreted guest commits its report only
after every body returns through the pinned production LeptosKit `WasmHost`.
Deliberate corruption and one-fuel exhaustion must reject before a report commit.
The compiled guest must pass the closed three-import SDK gate.

This fixture enables PDA, hashing, tree and DAS features. DAS uses deterministic
in-memory replies through the actual typed Client. It proves no external provider,
validator transition or installed desktop/Android/iOS application journey.
All fixture packages remain private and are excluded from placeholder publication.
