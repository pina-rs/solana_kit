# Generated Codama consumer

This private fixture contains eight client contract groups against the output of the packed NPM renderer. They cover literal instruction bytes and malformed inputs, borrowed codec composition and size rejection, imported signing keys, complete account/event discriminator predicates, positional optional roles, omitted suffixes, literal defaults without PDA recipes, and PDA helper names and account-free builders.

Generate all five program modules through the maintained packed-package test before running Cargo. The default `pda` feature ensures resolver helpers compile. The `guest` exports the ordinary LeptosKit ABI and runs these same assertions before emitting its result. Source alone is not evidence of native, browser, WASI or LeptosKit runtime execution.

This is application client code. Use Pina or the official Solana program libraries for on-chain programs.
