# Attestation, Squads and recurring Subscriptions clients

The three clients provide exclusively off-chain application APIs. Use Pina or
official Solana program libraries for on-chain programs. Native verification
executes 83 original behavior owners and three public documentation examples.

| Client                  | Original behavior owners | Model scope                                                                           |
| ----------------------- | -----------------------: | ------------------------------------------------------------------------------------- |
| Attestation Service     |                       22 | 12 instructions, three accounts, 26 schema types, seven PDA recipes, 12 errors        |
| Squads V4               |                       48 | 36 instructions, nine accounts, 11 named values, eight PDA recipes, 45 errors         |
| Recurring Subscriptions |                       13 | 18 instructions, six account/PDA identities, seven events, six PDA recipes, 78 errors |

The clients use Kit-owned addresses, instruction metadata, account snapshots and
bounded codecs. Default normal/build graphs contain only the client, Core and
base58. Optional pda forwards Core's deterministic cryptography. The maintained
dependency gate checks 144 target-specific default/PDA normal/build views for all 11
clients in its scope and rejects an injected Tokio dependency through the same
checker used for each actual graph.

The remaining-programs workflow executes the exact 83-body registry natively, in
Chrome, in both WASI previews and through the pinned production LeptosKit
WasmHost. WASI output must match the entire named native stream. The browser,
native and WASI corruption controls require the exact intentional panic marker.
The interpreted host requires one successful report commit, rejects one-fuel
execution and rejects a corrupt guest before any commit. Its compiled import
table must pass the closed SDK gate. Heavy host and platform builds belong in CI.

All generated modules and the registry must regenerate byte identically. Private
source adapters make separate Attestation/Squads account prefixes and Subscriptions
event prefixes explicit. Ordinary public Codama discriminators continue to
constrain declared bytes. Subscriptions accounts retain their explicitly declared
fields, including the empty EventAuthority PDA contract. Resolver output uses
named role capacities and separates derivation, allocation and role construction.

The read-only primary auditors compare all Attestation and Squads model shapes to
checksum-pinned external IDLs. Those IDLs are temporary verification inputs and
are not distributed by this repository. Source/licensing limits remain in each
crate's notices. The public Subscriptions generator consumes its retained pinned
MIT Codama model.

The source gate retains 7,295 exact original 14-field declaration records and their
defining-file hashes, including 1,794 new records. All original statuses remain
unchanged. This is provenance and scope evidence; it does not complete the
per-declaration behavioral adjudication. Actual deployed transitions and generated
installed desktop, Android and iOS end-to-end journeys remain required where
specified by the implementation plan.
