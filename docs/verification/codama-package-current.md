# Current Codama NPM package acceptance

On 2026-11-04, the off-chain Codama Rust renderer package passed its local
packed-package acceptance and the generated consumer executed on every promised
host. This is local execution evidence for the off-chain application client
fixture. It does not publish the package, qualify the full SDK workspace, or
complete on-chain, validator, device, wallet or network work.

Base checkout was `3985ed7dd8d052b531b98029566e68fe092808a6`. The changes under
review preserve the writer policy and public API: only test fixture creation,
the packed-consumer preserve option, documentation and fixture harness evidence
changed.

Parent review moved artifact preservation after the consumer checks and required a fresh export
directory. A repeated export fails instead of replacing existing caller files.

and `/dev/null` global configuration. `CARGO_NET_OFFLINE=true`,

## Reproduce

`REPO` is this checkout, `R1_99` and `R1_89` are the installed toolchain `bin`
directories, `WASMTIME` is Wasmtime 50.0.0, and `CHROME`/`CHROMEDRIVER` are the
matching 156.0.8078.80 executables.

```sh
cd "$REPO/packages/codama-renderers-rust-solana-kit"
export PATH="$R1_99:$PATH" CARGO="$R1_99/cargo" RUSTC="$R1_99/rustc" RUSTDOC="$R1_99/rustdoc"
export CARGO_NET_OFFLINE=true CARGO_INCREMENTAL=0 CARGO_BUILD_JOBS=4
export NPM_CONFIG_USERCONFIG="$(mktemp)" NPM_CONFIG_GLOBALCONFIG=/dev/null
printf '%s\n' 'user-agent=build' > "$NPM_CONFIG_USERCONFIG"
npm ci --offline --ignore-scripts --no-audit --no-fund \
  --userconfig "$NPM_CONFIG_USERCONFIG" --globalconfig /dev/null
npm run build && npm run typecheck && npm test
export DPRINT MONOSTYLE MONOSTYLE_CONFIG="$REPO/monostyle.toml" \
  DPRINT_TYPESCRIPT_PLUGIN="$DPRINT_PLUGIN"
npm run format:dist
npm run check:package && npm pack --ignore-scripts --offline
npm run test:packed -- "$PWD/codama-renderers-rust-solana-kit-0.1.0.tgz" \
  "$REPO/verification/codama-consumer/generated"

cd "$REPO/verification/codama-consumer"
cargo generate-lockfile --offline
CARGO_TARGET_DIR="$PWD/target/native-current" cargo run --offline --locked --bin client
CARGO_TARGET_DIR="$PWD/target/native-1.89" RUSTC="$R1_89/rustc" \
  RUSTDOC="$R1_89/rustdoc" "$R1_89/cargo" run --offline --locked --bin client
CARGO_TARGET_DIR="$PWD/target/browser" WASM_BINDGEN_USE_BROWSER=1 CHROME="$CHROME" \
  CHROMEDRIVER="$CHROMEDRIVER" WASM_BINDGEN_TEST_DRIVER_TIMEOUT=30 \
  cargo test --offline --locked -p packed_counter_client --lib \
  --target wasm32-unknown-unknown -- --nocapture
for target in wasm32-wasip1 wasm32-wasip2; do
  CARGO_TARGET_DIR="$PWD/target/wasi" cargo build --offline --locked \
    -p packed_counter_client --bin client --target "$target"
  "$WASMTIME" run "$PWD/target/wasi/$target/debug/client.wasm"
done
CARGO_TARGET_DIR="$PWD/target/leptoskit" cargo build --offline --locked --release \
  -p packed_counter_guest --target wasm32-unknown-unknown
cd "$REPO" && cargo xtask imports \
  "$REPO/verification/codama-consumer/target/leptoskit/wasm32-unknown-unknown/release/packed_counter_guest.wasm"
cargo generate-lockfile --offline --manifest-path verification/codama-consumer/host/Cargo.toml
cargo run --offline --locked --manifest-path verification/codama-consumer/host/Cargo.toml -- \
  "$REPO/verification/codama-consumer/target/leptoskit/wasm32-unknown-unknown/release/packed_counter_guest.wasm"
```

Use a fresh checkout for the export command: `verification/codama-consumer/generated` must not already
exist. Later host commands reuse those preserved bytes without re-exporting them.

## Other gates and limits

`cargo test --manifest-path tools/codama-renderer/Cargo.toml --all-features
--locked --offline` passed 116 tests with 0 failures. Warning-denied Clippy
passed for the native consumer, the browser test target, the guest and the
LeptosKit host. `cargo doc --no-deps` with `RUSTDOCFLAGS=-D warnings` passed for
the consumer and guest. `dprint check` and `monochange check` passed. `cargo
xtask style` passed with every scored file at or above 90; the final run scored
2202 files with repository readability 97.20 and complexity 98.52.

The Rust 1.89.0 toolchain on this machine does not have its Clippy component
installed, so the 1.89 proof is execution only. Strict Clippy and documentation
ran on Rust 1.99.1. The 1.89 result is not inflated or substituted: the same
generated bytes compiled and executed, but warning-denied Clippy for that
toolchain was not run locally. The browser run emitted wasm-bindgen's
deprecated initialization-parameter warning; it did not affect the passing
test.

These are local macOS executions. They do not establish Linux or CI behavior,
cross-machine reproducibility of the local artifact hashes, publication
readiness, full SDK workspace acceptance, real network/RPC behavior, installed
applications or on-chain programs. The archive was not uploaded. No device,
wallet, validator, system-security setting or secret was used.
