# Stake clients

Deterministic Stake program data codecs, ordered instruction builders, metadata-preserving account decoding and pure instruction plans using Kit-owned values. The `no_std + alloc` dependency graph adds the existing small System client to core for account creation; it contains no host runtime or Solana SDK dependency.

This crate is exclusively for off-chain application clients. Use Pina or official Solana libraries for on-chain programs.

The exact pinned source, source discrepancies, and verification limits are recorded in the Stake/Loader receipt. Publication is disabled.
