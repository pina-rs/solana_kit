# Source provenance

Surfpool wire names, model fields, defaults and operation contracts derive from
the MIT-licensed Dart Solana Kit Surfpool package at commit
`0138bb956d2d81ccc0c56edc602401c0df2f2b46` in
<https://github.com/openbudgetfun/solana_kit>.

The original MIT notice is retained in `MIT-DART.txt`. New original Rust code is
offered under the Unlicense. No upstream networking implementation, native
runtime, CLI binary, credential or Solana SDK dependency is bundled.
