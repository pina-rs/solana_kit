# Source provenance

Jupiter wire names, fields, routes and defaults derive from the MIT-licensed Dart
Solana Kit Jupiter package at commit
`0138bb956d2d81ccc0c56edc602401c0df2f2b46` in
<https://github.com/openbudgetfun/solana_kit>.

Its MIT notice is retained in `MIT-DART.txt`. New original Rust code uses the
Unlicense. The SDK reuses its existing REST transport and JSON admission; no
upstream networking implementation or credentials are bundled.
